# 税金計算アプリケーション

## 概要
給与計算に関連する税金や保険料を計算するWebアプリケーションです。月給と賞与から、所得税、住民税、社会保険料などを計算し、社員負担額と会社負担額を表示します。

## 特徴
- シンプルで直感的なユーザーインターフェース
- レスポンシブデザインによるマルチデバイス対応
- ダークモードサポート
- リアルタイムの計算結果表示
- 詳細な税金・保険料の内訳表示

## 技術スタック
- HTML5
- TailwindCSS (スタイリング)
- Vanilla JavaScript (ロジック実装)

## 計算項目
### 社員負担
- 所得税
- 住民税
- 健康保険料
- 厚生年金保険料（オプション）
- 介護保険料（オプション）
- 雇用保険料

### 会社負担
- 住民税
- 健康保険料
- 厚生年金保険料（オプション）
- 介護保険料（オプション）
- 雇用保険料
- 労災保険料
- 子育て拠出金（オプション）

## 使用方法
1. index.htmlをブラウザで開く
2. 月給（万円）を入力
3. 賞与（万円）がある場合は入力
4. 適用される保険料のチェックボックスを選択
5. 「計算」ボタンをクリック
6. 結果が表示され、年間・月間の詳細な内訳を確認可能
